# Alexander Antamba · Web personal

Sitio estático de Alexander Antamba (fotógrafo y filmmaker), publicado en Cloudflare.

- `public/index.html` — la página.
- `public/img/` — fotos, logos y videos (`img/trabajos`).
- `wrangler.jsonc` — configuración de Cloudflare (sirve la carpeta `public`).

Cada cambio que se sube a la rama `main` se publica automáticamente.
